Aula de CSS

Css é uma linguagem declarativa auxiliar documentos html para estilização de definição de comportamento. O css pode ser declarado de três formas distintas.

  1. Na tag style, definida no cabeçario do HTML;
  2. Em um documento externo por meioda tag link;
  3. Inline no proprio elemento HTML.

CSS possui diversas formas de selecionar em quais elementos html uma regra sera aplicada

Seletores:
  • seletores por elemento
  • Seletor universal " * " ;
  • id identificador unico " # " .
  • classe ou categoria " . " .
  • seletor por descente " " . A B
