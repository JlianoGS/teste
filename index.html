O git é um sistema de controle de versão distribuido

Comandos do git

  • git init : inicializa um repositorio git
  • git status
  • git add nome-arquivo.txt : adiciona no stage
  • git commit -m "comenttario" : cria um commit no seu repositorio local
  • git log : exibe os commits da branch atual do repositorio local
  • git switch branch : muda de branch
  • git switch -c cria-nova-branch : muda de branch
  • git diff : exibe a diferença do commit apontado por HEAD e worktree
